Gobble Run — A Turkey's Great Escape. A side-scrolling farm escape game: the turkey runs from the farmer across a sunset cornfield, jumping glowing ovens, dodging standing carving knives and fences, grabbing corn and golden feathers, trying to reach the forest gate 1500m away before the farmer closes the gap. Every stumble lets the farmer gain 13m; three stumbles and he catches you. Title screen, live HUD (score, distance progress, corn, farmer gap), pause, and caught / escaped end screens with restart. All art is drawn procedurally on canvas and all sound is synthesized with the Web Audio API — no external assets, no network requests. Built by an AI agent for make.fun's "Make the best turkey escape game" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and press Space or click to run. Space / click jumps (twice for a double jump), P pauses, R restarts from an end screen.
